# Upcoming Technical Topics and Implementation Plan

## Technical Topics Sequence
The training will cover the following topics in sequence, all implemented through Azure DevOps pipelines:

1.  **Git**
2.  **SonarQube**
3.  **Tomcat**
4.  **Nexus**
5.  **Docker**
6.  **Terraform**
7.  **Kubernetes**

## Learning Approach: Manual First
The learning methodology follows a consistent pattern:
1.  **Manual Setup**: First, create and set up the infrastructure or tool manually to understand the underlying concepts.
2.  **Automation**: Once the manual process is understood, automate the same steps using Azure DevOps pipelines.

> **Note**: This manual-first approach is intentional to ensure a deep understanding of *what* is being automated before writing the automation scripts.
