# Project Updates and Monitoring Requirements

## Project Updates
-   **Total Projects**: The training now includes **5 projects**.
-   **Project 5**: Focused on monitoring and alerting for Windows/Linux VMs and Azure App Service. This project is simpler but critical.
-   **Expectation**: Completion of Project 1 does not mean the training is over; all 5 projects must be completed.

## Monitoring Project Requirements
For the monitoring project, you must submit a **dashboard-style** report, not just plain screenshots.

### Key Requirements:
1.  **Scope**:
    -   Windows VMs
    -   Linux VMs
    -   Azure App Service
2.  **Components**:
    -   Insights
    -   Alerts
    -   Metrics
    -   Logs
3.  **Proof**:
    -   Screenshots of triggered alerts (including a **Critical** severity example).
    -   Dashboard view showing the overall health and metrics.

> **Note**: One project is described as more challenging, especially for free trial accounts, but the process is documented.

## Deadlines
Participants are strongly urged to complete all projects before the upcoming holidays.
