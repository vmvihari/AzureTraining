# Azure DevOps Account Setup

## Creating an Account
-   **Cost**: Free.
-   **Link**: Linked to your Azure Cloud Subscription.
-   **Free Grant**: Includes **1,800 free minutes** per month for CI/CD pipelines.

## Configuration Warnings
> **Important**: Do NOT change default settings related to **Parallel Jobs** or **Test Plans** without understanding the impact. These can incur unnecessary charges.

## Git in Azure DevOps
-   **Git**: Used for both application source code and infrastructure/automation scripts.
-   **Azure DevOps Repos**: The hosting platform for your Git repositories.
